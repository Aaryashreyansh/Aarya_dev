# 17. DevOps Interview Questions
Try answering in your own words before consulting documentation.

## Linux
1. Process vs thread?
2. What do file permissions represent?
3. How would you investigate an unresponsive service?

## Networking
4. What happens during DNS resolution?
5. Compare TCP and UDP.
6. What is TLS for?

## Git
7. Explain merge vs rebase.
8. What is a pull request?
9. How would you resolve a merge conflict?

## Docker and Kubernetes
10. Image vs container?
11. What is a Docker volume?
12. Pod vs Deployment?
13. Readiness vs liveness probe?

## CI/CD and Cloud
14. What is a pipeline artifact?
15. What is infrastructure as code?
16. Why use least-privilege IAM?
17. Why are budgets and cleanup important?

## Observability
18. Metrics vs logs vs traces?
19. What makes an alert actionable?

Practice format: definition → why it matters → example → trade-off.
