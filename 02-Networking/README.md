# 02. Networking 🌐
Topics: IPv4/IPv6, private/public IP, subnet basics, DNS, TCP vs UDP, ports, HTTP/HTTPS, TLS, SSH, routing, NAT and firewalls.

## Safe starter lab
    ping -c 4 example.com
    nslookup example.com
    curl -I https://example.com

## Exercises
1. Explain what happens after entering a website address in a browser.
2. Identify the purpose of ports 22, 53, 80 and 443.
3. Compare a DNS lookup with an HTTP request.
4. Draw a client-router-server diagram.

Only test networks and hosts you own or have permission to assess.
