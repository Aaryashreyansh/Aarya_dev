# 16. Practical Projects 🧪
Each project should include a README, architecture sketch, setup steps, test evidence, security notes and cleanup instructions.

## Beginner
1. Linux system information report (read-only)
2. Python log summarizer using sample logs
3. Bash backup simulator using a test directory
4. Git branching and pull-request workflow

## Intermediate
5. Containerize a small Python web app
6. Docker Compose local app with a database
7. CI pipeline that runs tests and linting
8. Prometheus/Grafana local demo dashboard

## Advanced
9. Kubernetes deployment in a local cluster
10. Terraform plan for a disposable sandbox
11. Ansible configuration of a local VM
12. End-to-end source → test → container → local deployment → monitoring demo

Do not deploy public services or spend money without permission and cost controls.
