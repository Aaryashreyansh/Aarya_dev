# 09. AWS ☁️
Learn IAM, Regions and Availability Zones, VPC concepts, compute, object storage, databases, monitoring and billing.

Exercises: explain IAM roles and policies, draw a VPC with public/private subnets, compare object and block storage, and create a cost/cleanup checklist.

Review current pricing, free-tier limits, permissions and cleanup steps before provisioning. Free tiers have limits and can change.
