# Contributing
Beginner-friendly contributions welcome: improve Hindi explanations, add tested labs, fix typos, document troubleshooting or add interview questions.

## Lab format
1. Goal and prerequisites
2. Concept
3. Commands with explanations
4. Expected output
5. Exercise
6. Cleanup and safety notes

## Pull request checklist
- [ ] Instructions tested in an appropriate lab
- [ ] No credentials or personal data included
- [ ] Destructive commands clearly explained
- [ ] Cleanup steps included
- [ ] Links and formatting checked

Be respectful. Document only authorized administration and lab activities.
