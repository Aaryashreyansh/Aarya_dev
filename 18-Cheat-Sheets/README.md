# 18. Cheat Sheets
Quick reminders. Check official documentation for current flags and behavior.

## Git
- git status: inspect working tree
- git add: stage changes
- git commit: record staged changes
- git log --oneline: compact history
- git switch -c feature/name: create and switch branch

## Linux
- pwd: current directory
- ls -la: list files including hidden entries
- df -h: filesystem space
- du -sh PATH: size of a path
- ps: process snapshot

## Docker
- docker --version: client version
- docker image ls: list images
- docker ps: list running containers
- docker logs CONTAINER: view container logs

## Python
- python --version: interpreter version
- python -m venv .venv: create virtual environment
- python -m pip list: list installed packages

Check paths, permissions and impact before running commands.
