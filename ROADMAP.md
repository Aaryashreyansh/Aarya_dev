# Aarya DevOps Learning Roadmap

## Stage 1: Foundations
- [ ] Linux terminal, files, permissions and processes
- [ ] Networking: IP, DNS, ports, HTTP and SSH
- [ ] Git commits, branches, merges and pull requests
- [ ] Python basics and automation
Milestone: Write a Python script, version it with Git, and explain a browser-to-server request.

## Stage 2: Containers and delivery
- [ ] Docker images, containers, volumes and networks
- [ ] Docker Compose
- [ ] CI pipeline: build, test and package
Milestone: Build and test a small app automatically.

## Stage 3: Cloud and infrastructure
- [ ] Choose AWS, Azure or GCP first
- [ ] IAM, networking, compute, storage and billing
- [ ] Terraform and state safety
- [ ] Ansible and idempotence
Milestone: Provision and clean up a disposable lab.

## Stage 4: Orchestration and observability
- [ ] Kubernetes Pods, Deployments and Services
- [ ] ConfigMaps, Secrets and probes
- [ ] Metrics, logs, dashboards and alerts

## Stage 5: Portfolio
- [ ] Complete three projects
- [ ] Add architecture diagrams and setup instructions
- [ ] Document troubleshooting, security and cleanup

Safety: never commit secrets; use least privilege; set cloud budgets; clean up resources.
