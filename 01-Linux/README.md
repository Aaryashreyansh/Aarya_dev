# 01. Linux 🐧
Topics: terminal, shell, paths, filesystem, files, permissions, ownership, processes, services, logs, package managers and environment variables.

## Safe starter lab
    pwd
    mkdir -p ~/devops-lab/linux
    cd ~/devops-lab/linux
    printf 'Aarya DevOps\n' > notes.txt
    cat notes.txt
    ls -la

## Exercises
1. Create folders for notes, scripts and logs.
2. Display the first and last lines of a sample text file.
3. Explain process vs service.
4. Check disk usage and explain the output.

Avoid sudo, recursive deletion, disk formatting and permission changes until you understand their impact.
