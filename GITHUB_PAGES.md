# Publish Aarya DevOps Academy with GitHub Pages

The website is a static site in the repository root: `index.html`. It does not need a server, build tool, API key or paid hosting.

## Enable it
1. Open the repository: https://github.com/Aaryashreyansh/Aarya_dev
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Press **Save** and wait for GitHub Pages to publish.

## Website address
https://aaryashreyansh.github.io/Aarya_dev/

Publishing can take a few minutes. If the page is not available immediately, check the Pages section for the deployment status.

## Update the website
Edit `index.html` and commit changes to `main`. GitHub Pages will publish the updated static site automatically.

## Notes
- Progress is stored in local browser storage on the visitor's device.
- The site does not collect login credentials or send progress to a server.
- No paid server is required. GitHub Pages usage is subject to GitHub's current plan and Pages limits.
